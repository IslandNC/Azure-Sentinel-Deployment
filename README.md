# Azure-Sentinel-Deployment

## Project Overview

This repository documents a hands-on deployment of **Microsoft Azure Sentinel**, a cloud-native Security Information and Event Management (SIEM) and Security Orchestration, Automation, and Response (SOAR) solution. This project was completed as part of the **CyberXcel** cybersecurity training program.

---

## Objectives

- Deploy and configure Microsoft Azure Sentinel in a live Azure environment
- Connect data sources via built-in data connectors
- Set up Log Analytics Workspace for centralized log ingestion
- Create analytic rules to detect suspicious activity
- Explore incident management and investigation workflows
- Understand how SIEM solutions support real-world SOC functions

---

## Technologies Used

- Microsoft Azure Sentinel (SIEM/SOAR)
- Azure Log Analytics Workspace
- Azure Active Directory
- Microsoft Defender for Cloud
- KQL (Kusto Query Language) for log queries and detection rules

---

## Key Steps Performed

1. Provisioned Azure Sentinel - Created and linked a Log Analytics Workspace in the Azure Portal
2. Connected Data Connectors - Enabled connectors for Azure AD, Microsoft Defender, and Azure Activity logs
3. Configured Analytic Rules - Built detection rules using KQL to identify threats such as failed login attempts and privilege escalation
4. Reviewed Incidents - Investigated auto-generated incidents and triaged alerts in the Sentinel dashboard
5. Explored Workbooks - Utilized built-in workbooks for visual security monitoring and reporting

---

## Training Context

This deployment was completed as a guided hands-on lab through the **CyberXcel** training program, designed to build practical skills in cloud security monitoring, threat detection, and incident response.
